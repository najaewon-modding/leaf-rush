# Leaf Rush

나무를 벤 뒤 공중에 남은 나뭇잎이 더 빠르게 사라지도록 만들어 주는 가벼운 NeoForge 모드입니다.

바닐라의 나뭇잎 부패 조건과 드롭은 그대로 유지하면서, 통나무와 연결이 끊어진 나뭇잎만 빠르게 정리합니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97+` |

## 주요 기능

- 나무를 벤 뒤 남은 나뭇잎을 빠르게 제거
- 통나무와 정상적으로 연결된 나뭇잎은 그대로 유지
- 플레이어가 직접 설치한 나뭇잎은 자동으로 사라지지 않음
- 묘목, 막대기, 사과 등 기존 나뭇잎 드롭 유지
- 별도의 설정이나 조작 없이 자동으로 동작

## 동작 방식

평소처럼 나무의 통나무를 제거하면, 연결이 끊어진 나뭇잎이 짧은 시간 안에 부패하기 시작합니다.

Leaf Rush는 나뭇잎을 즉시 전부 삭제하지 않기 때문에 자연스럽게 순차적으로 사라지는 모습을 유지합니다.

### 통나무와 연결된 나뭇잎

아직 유효한 통나무와 연결되어 있는 나뭇잎은 그대로 남습니다. 따라서 나무의 일부만 잘랐거나 장식용으로 통나무와 나뭇잎을 함께 사용한 경우 정상적인 나뭇잎까지 무조건 제거하지 않습니다.

### 플레이어가 설치한 나뭇잎

플레이어가 직접 설치한 나뭇잎은 자동 부패 대상에서 제외됩니다. 건축이나 장식에 사용한 나뭇잎이 Leaf Rush 때문에 사라지지 않습니다.

### 기존 드롭 유지

Leaf Rush는 나뭇잎 종류별 기존 드롭을 그대로 따릅니다. 따라서 나뭇잎이 사라질 때 얻을 수 있는 묘목, 막대기, 사과 등의 드롭도 기존 Minecraft와 동일하게 처리됩니다.

## 사용 방법

설치 후 별도의 명령어나 설정 없이 자동으로 동작합니다.

1. 평소처럼 나무의 통나무를 제거합니다.
2. 연결이 끊어진 나뭇잎이 빠르게 부패합니다.
3. 통나무와 연결된 나뭇잎과 플레이어가 설치한 나뭇잎은 그대로 유지됩니다.

## 설치

1. Minecraft `26.1.2`와 호환되는 NeoForge를 설치합니다.
2. Leaf Rush JAR 파일을 `mods` 폴더에 넣습니다.
3. 멀티플레이에서는 서버의 `mods` 폴더에 설치합니다.
4. Minecraft 또는 서버를 실행합니다.
