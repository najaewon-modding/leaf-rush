# Leaf Rush

나무를 벤 뒤 공중에 남은 나뭇잎이 바닐라 규칙을 유지하면서 빠르게 사라지도록 만드는 가벼운 NeoForge 모드입니다.

Leaf Rush는 나뭇잎 블록을 강제로 삭제하지 않습니다. 부패 후보가 된 나뭇잎을 짧은 시간 뒤 다시 검사한 다음 해당 블록의 **기존 Minecraft `randomTick` 로직**을 실행하여, 바닐라의 거리 판정과 아이템 드롭 규칙을 그대로 사용합니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97+` |
| 동작 대상 | 서버 월드의 나뭇잎 부패 |

## 주요 기능

- 나무 제거 후 분리된 나뭇잎의 부패를 빠르게 진행
- 바닐라 나뭇잎 거리 및 부패 조건 유지
- 바닐라 `randomTick`을 사용하여 기존 드롭 규칙 유지
- 통나무와 정상적으로 연결된 나뭇잎은 그대로 유지
- 플레이어가 설치한 `persistent` 나뭇잎은 자동 부패 대상에서 제외
- 한 번에 즉시 삭제하지 않고 짧은 무작위 지연을 두어 자연스럽게 처리

## 동작 방식

Leaf Rush는 주변 블록 변화로 인해 나뭇잎이 부패 후보가 되었을 때 해당 위치를 스케줄러에 등록합니다.

등록된 나뭇잎은 다음 범위의 무작위 지연 뒤 다시 처리됩니다.

```text
4~12 ticks
```

처리 시점에는 해당 블록이 여전히 로드되어 있고 나뭇잎인지, 그리고 `persistent` 상태가 아닌지를 다시 확인합니다. 조건을 만족하면 나뭇잎 블록 자체의 `randomTick`을 호출합니다.

이 방식 때문에 Leaf Rush가 별도의 독자적인 나뭇잎 삭제 규칙을 만들지 않습니다.

### 바닐라 부패 규칙 유지

실제로 블록이 사라질지 여부는 최종적으로 Minecraft의 나뭇잎 로직이 결정합니다. 따라서 유효한 통나무와 계속 연결되어 있는 나뭇잎은 Leaf Rush가 처리 대상으로 잡더라도 바닐라 판정에 따라 남습니다.

### 플레이어가 설치한 나뭇잎 보호

`LeavesBlock.PERSISTENT` 속성이 `true`인 나뭇잎은 부패 후보에서 제외합니다. 일반적으로 플레이어가 직접 설치한 나뭇잎 장식이 여기에 해당하므로, 건축용 나뭇잎이 자동으로 사라지는 것을 방지합니다.

### 드롭 처리

Leaf Rush는 `setBlock(..., AIR)` 같은 방식으로 나뭇잎을 직접 지우지 않고 원래 블록의 `randomTick`을 사용합니다. 따라서 묘목, 막대기, 사과 등 나뭇잎 종류별 기존 드롭 동작을 그대로 따릅니다.

## 설치

1. Minecraft `26.1.2`와 호환되는 NeoForge를 설치합니다.
2. Leaf Rush JAR 파일을 `mods` 폴더에 넣습니다.
3. 멀티플레이에서는 서버의 `mods` 폴더에 설치합니다.
4. Minecraft 또는 서버를 실행합니다.

별도의 설정 파일이나 명령어는 필요하지 않습니다.

## 사용 방법

설치 후 별도 조작 없이 자동으로 동작합니다. 평소처럼 나무의 통나무를 제거하면 분리된 나뭇잎이 빠른 주기로 바닐라 부패 판정을 받습니다.

## 기술 정보

- 모드 ID: `njw_leaf_rush`
- 부패 예약 지연: `4~12 ticks`
- 처리 대상: `minecraft:leaves` 태그에 포함되는 비영구 나뭇잎
- 실제 부패 처리: 대상 블록의 기존 `randomTick`
